# API Evangelist

> 16 years of independent research on the technology, business, policies, and people of HTTP APIs — by Kin Lane.

API Evangelist is a federated network of knowledge bases built on 5,000+ blog posts spanning 2010–2026. The research covers every aspect of API operations, from design and governance to AI agents and the programmable enterprise. Run by Kin Lane.

## Core Content

- [Blog](https://apievangelist.com/2026/): Current writing on APIs, AI agents, governance, and the API industry
- [Conversations](https://conversations.apievangelist.com): Transcripts and summaries of conversations with API practitioners
- [Rules](https://rules.apievangelist.com): Machine-readable API governance rules (Spectral/OpenAPI)
- [Guidance](https://guidance.apievangelist.com): Guidance for API producers and consumers
- [Policies](https://policies.apievangelist.com): API policies for enterprise operations
- [Standards](https://standards.apievangelist.com): API standards landscape
- [Strategies](https://strategies.apievangelist.com): API strategy patterns
- [Vocabularies](https://vocabularies.apievangelist.com): API vocabulary and terminology
- [Schema](https://schema.apievangelist.com): API-related schema definitions
- [Properties](https://properties.apievangelist.com): API property patterns
- [Experiences](https://experiences.apievangelist.com): API consumer experience patterns
- [Videos](https://video.apievangelist.com): Video content on APIs

## API & MCP

The whole network is programmable — every resource above is available via a REST API and an MCP server.

- [Developer Portal](https://developer.apievangelist.com/): documentation, quickstarts, and the API reference
- [Network API](https://api.apievangelist.com/v1): REST over stories, areas, building blocks, papers, conversations, services, and vocabulary — keyless free tier (5 req/s, 1,000/day)
- [OpenAPI](https://developer.apievangelist.com/apis/apievangelist-v1-openapi.yml): the machine-readable contract
- [MCP Server](https://mcp.apievangelist.com/mcp): Streamable HTTP, 17 tools including get_overview and guide_topic concierge tools ([server card](https://apievangelist.com/.well-known/mcp/server-card.json))
- [API Catalog](https://developer.apievangelist.com/.well-known/api-catalog): RFC 9727 linkset of every machine-readable surface
