This is the developer front door to the **[API Evangelist](https://apievangelist.com)** network —
sixteen years of API research served as **one API and one MCP server**: 5,250+ stories, 77 focused
topic areas, 2,600+ governance building blocks (guidance, rules, policies, standards, strategies,
schema, properties, experiences, lifecycle), white papers, conversations, videos, tools, research
timelines, services, and the API vocabulary.

## Two ways in

| Surface | Where | Best for |
| --- | --- | --- |
| **REST API** | `https://api.apievangelist.com/v1` — [API Reference](/api) | Search, browse, and integrate any resource type |
| **MCP server** | `https://mcp.apievangelist.com/mcp` — [MCP Server](./mcp-server) | AI agents; start with `get_overview` and `guide_topic` |
| **Governance & Discovery API** | `https://api.apievangelist.com/v1/governance` — [Governance](/governance/index) | Lint, score, test and fix API descriptions and the rules that govern them |

## What's inside

- **Stories** — 5,250+ blog posts since 2010 (`/posts`)
- **Areas** — 77 focused topic areas and their related-area graph (`/areas`)
- **Guidance** — editorial guidance, browsable by section: history, technology, business,
  politics, governance, and evangelism (`/guidance`, `/guidance/sections/{section}`)
- **Governance** — `/policies`, `/rules`
- **Toolbox** — `/standards`, `/solutions` (740+ third-party services), `/tools` (525+
  open-source tools), `/schema`, `/properties`
- **Operations** — `/strategies`, `/experiences`, `/lifecycle`
- **Media** — `/conversations`, `/videos` (transcript-searchable), `/papers`, `/newsletters`
- **Reference** — the API vocabulary (`/vocabulary`)
- **Timelines** — the api, resources, industries, and people research timelines (`/timelines/{timeline}`)
- **Services** — Kin Lane's first-party offerings (`/services`)
- **Insights** — demand-side intelligence on 6,572 companies: what the Fortune 1000 and API providers build, buy, and hire for (`/insights`, `/insights/company/{slug}`)
- **Demand depth** — a company's dimensions read against the measured cohort, its peers, and its
  whitespace (`/insights/company/{slug}/dimensions`, `/peers`, `/whitespace`, `/signals`)
- **The demand inversion** — which companies show demand for a given service, tool, or standard.
  Every other route runs company → stack; this one runs stack → companies
  (`/insights/entities`, `/insights/entity/{kind}/{slug}`)
- **Standards measurement** — what a standards body actually ships, as opposed to what it
  describes: repositories published, how many graduated, who governs it, which companies pay for
  membership. Fourteen bodies profiled so far, free
  (`/standards/measured`, `/standards/{slug}/adoption`, `/coalition`, `/repositories`)
- **Contact** — every way to reach API Evangelist (`/contact`)

The Network API is read-only `GET`; the Governance API takes `POST` bodies. Both have a keyless
free tier — see [Authentication](./authentication).
